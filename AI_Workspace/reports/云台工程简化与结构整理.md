# H723 云台工程：当前架构与删减边界

核对日期：2026-11-02。本报告只描述本目录源码和独立工具的当前状态。判定依据为 Keil Target、启动入口、任务创建、IRQ/DMA/回调及 MAP。历史时期的材料在 `reports/history/`。

## 编译边界

`MDK-ARM/CtrlBoard-H7_IMU.uvprojx` 仅有 `CtrlBoard-H7_IMU` Target：STM32H723VGTx，DFP 3.1.1，ARM Compiler 5.06 update 7。宏为 `USE_HAL_DRIVER,STM32H723xx`；110 个 Keil 文件条目均存在，均在本目录。`User/APP/robot_param.h` 选择 `Infantry_robot`、`Steering_wheel`、`yaw_pitch_direct`、`friction_3508`、`gimbal_board`、`debug`、`Cap_off`。本目录没有 Git 仓库，按文件恢复使用 `AI_Workspace/snapshots/`。

## 运行职责

| 链路 | 当前调用与作用 |
| --- | --- |
| 启动 | `Core/Src/main.c` 初始化时钟、GPIO、DMA、SPI2、FDCAN、USART1、UART5、USART10、UART7、ADC、定时器及 OCTOSPI，再调用 `MX_FREERTOS_Init` 与 `osKernelStart` |
| 任务 | `Core/Src/freertos.c` 创建 `defaultTask`、`gimbalTask`、`cali`、`auto_aim`、`COMM_APP`、`message`、`imuTask`；`defaultTask` 初始化 USB |
| 控制输出 | `gimbalTask` 管理 Yaw/Pitch 与射击；Yaw 与拨弹使用 DJI CAN，Pitch 使用 DM EMIT；现有控制参数、单位、周期、初始化和故障输出未改 |
| 通信 | USART1 收 28 字节状态帧、发 46 字节帧；发帧包含 19 字节 VTM 载荷与 7 字节清零预留。UART5 是当前遥控输入；USB uproto 承担自瞄和主机通信 |
| 测距与触发 | `COMM_APP` 初始化 USART10 TFmini；接收与错误回调调用 TFmini；CAM_TRIG EXTI 触发相机事件 |
| 传感与持久化 | BMI088、Mahony、温控及 `cali` 保留；OCTOSPI/W25Q64 保持既有校准布局、有效标志及写入顺序 |

## 保留与待确认

`User/Communication/example/device` 是运行中的 USB、自瞄、TFmini、时间同步业务，必须保留。VTM 结构虽不再从 UART7 解析，仍由 `vtm_data_init` 填入安全默认值，并由 46 字节板间帧发送，必须保留其结构尺寸和初始化。UART7 自身仍由启动代码、DMA、IRQ 使用；当前 `RC_TYPE=0` 时没有 UART7 接收消费者，现车接线及用途未确认，因此本批没有修改其引脚、时钟、DMA、IRQ 或初始化顺序。SHOOT_DETECT EXTI2 进入 HAL，业务回调未消费该信号；也待实体用途确认。

`User/Communication/core/CRC8_CRC16.c` 与 Keil 编译的 `User/Controller/CRC8_CRC16.c` 字节相同，但本目录主机示例 CMake 引用前者。当前机器缺少主机 CMake/C++ 编译器；在主机示例可验证前保留双份。`toe_is_error` 有控制消费者，但离线检测任务未创建；此为现有保护链缺口，不能将源码检查当作在线保护证据。`auto_aimTask` 调用的 VOFA 调试发送与 TFmini 共用 USART10；此行为需单独核对，不在简化批次中改通信语义。

## 生成器与验收界限

`.ioc` 记录 CubeMX 6.10.0 和 CMSIS-RTOS v1。安装的 CubeMX 6.17 在本项目隔离生成时出现内部错误，且生成稿丢失 FreeRTOS 任务入口；候选文件未应用到正式工程。[ST 的技术答复](https://community.st.com/stm32cubemx-mcus-29/unable-to-generate-freertos-code-after-migration-164098)确认该版本已不支持 CMSIS-RTOS v1。需用兼容版本在 `AI_Workspace/cache/cubemx/` 完成生成、编译、再生成和配置差异检查，或把 RTOS 迁移作为独立工作。

当前源码检查、ARMCC/Unicorn 离线帧检查和 Keil 编译均不证明实体设备行为。未烧录或操作设备。具体批次、完整日志和恢复索引见 [独立项目收敛记录](独立项目收敛-2026-11-02.md)。
